# Strategic Research Agent — Product Proposal

## Обоснование идеи

В компаниях большое количество аналитических задач требует ручной работы:

- исследование рынков
- анализ компаний
- анализ конкурентов
- сравнение технологий и инструментов
- валидация продуктовых идей
- подготовка аналитических отчетов

Для выполнения этих задач сотрудники вынуждены:

- искать информацию в интернете
- анализировать внутренние документы
- сравнивать источники
- собирать информацию из разных систем

Этот процесс занимает часы или дни работы аналитиков.

Strategic Research Agent — это AI-агент, который автоматизирует процесс исследования и аналитики.

Агент является частью корпоративной AI-платформы, которая включает:

- Knowledge Bases
- Agentic RAG
- обработку документов
- хранение данных
- мультиагентную архитектуру

Благодаря этому агент может анализировать не только интернет-источники, но и внутренние документы компании.

---

# Цель проекта

Разработать прототип AI-агента, который способен выполнять многошаговые исследования и генерировать структурированные аналитические отчеты.

Агент должен уметь:

- исследовать темы
- анализировать компании
- анализировать рынки
- сравнивать vendors
- валидировать продуктовые идеи
- предлагать стратегические рекомендации

---

# Метрики успеха

## Продуктовые метрики

- пользователь получает понятный структурированный research report
- отчет содержит ключевые выводы
- присутствуют ссылки на источники
- отчет помогает принять решение

---

## Агентские метрики

- агент строит план исследования
- агент использует несколько источников информации
- агент способен синтезировать данные из разных источников

---

## Технические метрики

- успешное выполнение research pipeline
- корректная работа retrieval
- latency выполнения исследования до ~60 секунд для PoC

# Потенциальные сценарии использования

Пример:

Research AI infrastructure market.

Агент выполняет:

- сбор источников
- анализ информации
- генерацию отчета

## Анализ компании

## Сравнение vendors

Пример:

Агент генерирует:

## Валидация продуктовой идеи

- рынок
- конкурентов
- потенциальный ICP
- риски
- возможные стратегии

# Edge cases

Возможные проблемные ситуации:

- недостаток источников
- противоречивые данные
- слишком широкая тема исследования
- устаревшая информация

Агент должен:

- показывать confidence
- указывать источники
- предупреждать о недостатке данных

# Ограничения

## Технические ограничения

- время выполнения исследования ограничено
- ограниченное количество источников
- ограничения web search API
- ограниченный объем документов в PoC

---

## Операционные ограничения

- бюджет на LLM inference
- ограниченные вычислительные ресурсы
- ограниченное количество тестовых документов

# Архитектурный набросок

Strategic Research Agent является частью AI-платформы.

Основные модули системы:

Research Agent  
Оркестрация исследования.

RAG Engine  
Поиск информации в Knowledge Base.

Web Search Tool  
Поиск информации в интернете.

Document Processor  
Обработка и индексирование документов.

Report Generator  
Генерация структурированного аналитического отчета.

---

# Потенциальный Data Flow

1. Пользователь отправляет запрос.

2. Агент анализирует задачу.

3. Агент строит план исследования.

4. Агент выполняет retrieval:

- web источники
- knowledge base
- внутренние документы

5. Агент анализирует полученную информацию.

6. Агент генерирует структурированный research report.

---

# Делегирование задач

LLM / Agent выполняет:

- построение плана исследования
- анализ текстов
- синтез информации
- генерацию отчета

Не делегируется LLM:

- хранение данных
- retrieval из базы
- orchestration pipeline
- управление инфраструктурой
